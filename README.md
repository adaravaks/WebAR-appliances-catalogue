# AR-Техника — WebAR-каталог бытовой техники

Веб-приложение — каталог бытовой техники с просмотром товаров в 3D и **примеркой в дополненной
реальности (AR) прямо в браузере смартфона**, без установки приложений. Модели показываются
в натуральную величину, поэтому можно оценить, впишется ли холодильник или стиральная машина в интерьер.

Курсовая работа по дисциплине «Разработка кроссплатформенных приложений дополненной реальности»,
РТУ МИРЭА, 2026.

**Демо:** https://adaravaks.github.io/WebAR-appliances-catalogue/

## Возможности

- каталог из 15 товаров в 4 категориях: фильтр по категории, поиск, сортировка;
- интерактивный 3D-просмотр модели: вращение, масштабирование, автоповорот;
- AR-примерка в реальном масштабе 1:1:
  - iPhone / iPad — AR Quick Look (ARKit), USDZ-файл формируется на лету;
  - Android — WebXR Device API или Google Scene Viewer (ARCore);
- выбор цвета корпуса: выбранный цвет попадает и в AR;
- отображение габаритных размеров прямо на модели;
- проверка «поместится ли в нишу» с учётом зазоров для вентиляции;
- избранное (сохраняется в браузере);
- QR-код для перехода с компьютера на смартфон;
- адаптивная вёрстка для смартфонов, планшетов и ПК.

## Технологии

| Компонент | Назначение |
|---|---|
| HTML5, CSS3, JavaScript (ES-модули) | интерфейс без сборщика и фреймворков |
| [`<model-viewer>`](https://modelviewer.dev) 4.4 (Google, BSD-3-Clause) | 3D-просмотр на базе three.js и запуск AR |
| glTF 2.0 / GLB | формат 3D-моделей |
| [glTF Transform](https://gltf-transform.dev) | конвейер подготовки моделей (масштаб, PBR-материалы) |
| Playwright | генерация превью для каталога |
| GitHub Pages | хостинг (HTTPS обязателен для доступа к камере) |

## Структура проекта

```
index.html              — оболочка приложения
css/styles.css          — стили, адаптивная вёрстка
js/main.js              — маршрутизация и экраны (каталог, товар, избранное, справка)
js/store.js             — данные каталога, фильтры, проверка ниши, избранное
js/viewer.js            — работа с <model-viewer>: AR, цвет, размеры, QR-код
data/catalog.json       — товары, категории, габариты, цвета
models/*.glb            — подготовленные 3D-модели (реальный масштаб)
posters/*.webp          — превью товаров для каталога
vendor/                 — model-viewer и генератор QR-кодов
tools/                  — скрипты подготовки моделей и превью
tools/source-models/    — исходные модели Kenney Furniture Kit (CC0)
```

## Локальный запуск

Нужен любой статический HTTP-сервер (ES-модули не работают через `file://`):

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000. AR на телефоне работает только по HTTPS, поэтому
для проверки AR используйте опубликованную версию на GitHub Pages.

## Подготовка моделей

```bash
cd tools
npm install
npm run models    # source-models/*.glb → ../models/*.glb (реальный масштаб, PBR)
npm run posters   # ../models/*.glb → ../posters/*.webp
```

Габариты, цвета и материалы корпуса задаются в `data/catalog.json`.

## Публикация

Settings → Pages → Build and deployment → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
